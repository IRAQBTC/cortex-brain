How to Use Cortex

📤 Export Handoff (.md)

The most powerful feature for AI Agents (Cursor/Claude). It generates a single Markdown file containing your project's README/STATE files (if any) plus the core codebase context. Download it and feed it to any AI to instantly onboard it to your project.

🗺 Dependency Map

Visualizes how files import each other. Use this to understand the architecture before making changes. Click "Reload" to refresh the graph.

🛡️ Security & 🧟 Dead Code

Uses heuristic checks to identify potential secret indicators and possible unused-function candidates. Results may include false positives or miss issues; verify findings manually before making changes.
